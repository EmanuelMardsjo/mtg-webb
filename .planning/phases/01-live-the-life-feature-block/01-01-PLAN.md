<objective>
Create a reusable `useParallax` hook in `@system/hooks` that drives the FeatureSpotlight block's smoothed 3-layer parallax. The hook subscribes to scroll via a single rAF-throttled listener and writes restrained per-layer translateY drift to CSS custom properties (`--parallax-text`, `--parallax-frame`, `--parallax-img`) on its ref node — never via React state, so no per-frame re-render. It is fully disabled (no listener, zero offsets) under `prefers-reduced-motion` and under the Storybook `force-reduced-motion` toolbar class, satisfying REQ-04.

Purpose: This hook is the sole new behavior dependency of the FeatureSpotlight block (plan 02). Building it first (wave 1) lets the block consume a tested contract instead of inventing scroll logic inline.
Output: `useParallax.ts`, `useParallax.test.tsx`, and a one-line addition to the hooks barrel.
</objective>

  <behavior>
    - Returns an object `{ ref }` where `ref` is a `useRef<HTMLDivElement | null>(null)`.
    - On mount under normal motion: attaches a single rAF-throttled `scroll` + `resize` listener (passive) that computes a 0->1 progress from `getBoundingClientRect().top / innerHeight` and writes `--parallax-text`, `--parallax-frame`, `--parallax-img` as `px` translateY strings on `ref.current` via `style.setProperty`.
    - Never calls `setState` per scroll frame (no re-render); all output is written to the DOM node.
    - Under reduced motion (either `prefers-reduced-motion: reduce` OR `document.documentElement.classList.contains('force-reduced-motion')`): early-returns from the effect, attaches no listener, and leaves the parallax vars unset (so CSS fallback `0px` applies).
    - Cleans up both listeners and cancels the pending rAF on unmount.
  </behavior>
  <action>
    Create `src/system/hooks/useParallax.ts` as a `.ts` file (no JSX), mirroring `useScrollFade.ts`. Define an `isReduced()` helper in the form from `useMagneticLean.ts` (guards `window`, checks the `force-reduced-motion` class on `document.documentElement`, then `window.matchMedia('(prefers-reduced-motion: reduce)').matches`) — do NOT use the simpler `prefersReducedMotion()` from useScrollFade, because the Storybook reduced-motion toolbar relies on the class check (PATTERNS correction 5 / Motion guidance). Declare uppercase module constants `TEXT_DRIFT = -18`, `FRAME_DRIFT = -28`, `IMG_DRIFT = -40` (px, restrained translateY only — no scale/rotate, per brand motion guardrail). Export `function useParallax()` returning `{ ref }` with `ref = useRef<HTMLDivElement | null>(null)`. In a `useEffect(…, [])`: `if (isReduced()) return` first (REQ-04: no listener => fully static); guard `const el = ref.current; if (!el) return`; inside a `requestAnimationFrame` callback compute `p = Math.min(1, Math.max(0, 1 - rect.top / vh))` then `target.style.setProperty('--parallax-text', \`${(p * TEXT_DRIFT).toFixed(2)}px\`)` and likewise for `-frame`/`-img`. IMPORTANT (REQ-02 / no-restricted-syntax): build every px string via template literals with numeric vars as shown — never write a bare `'18px'` style literal in this `src/system/**` file. Call the handler once immediately, register `scroll` and `resize` as `{ passive: true }`, and return a cleanup that removes both listeners and `cancelAnimationFrame(raf)`. Add a short TSDoc block (like `useMagneticLean`) noting it writes `--parallax-*` vars on the node, the CSS module consumes them, and it is disabled under reduced motion.
