# Phase 1 — UI Design Contract

> Visual and interaction contract for the **"Live the life" Feature block**. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **This is an ADAPTATION phase, not greenfield.** The visual direction is already decided by the source design (`design-import/claude-design/MTG-blocks/mtg-feature.js` + `mtg.css` `.feature`/`.editorial`). This contract specifies how that look maps onto the existing token-driven React design system — it does not re-invent the look. No new tokens, no new palette (hard constraint, PROJECT.md + brand guardrails).

---

## Source → Target Summary

| | Source (reference only) | Target (this contract) |
|---|---|---|
| Tech | Vanilla HTML + CSS + IIFE JS | React 18 + TS + CSS Modules |
| Markup | `.feature > .feature__inner > {.editorial, .feature__reveal > .feature__frame > .feature__img}` | `Section` → `Container` → centered editorial `Stack` + media frame |
| Reveal | Custom `IntersectionObserver` + `.rise`/`.anim-ready`/`.is-revealed` classes | `useReveal()` hook (`@system/hooks`) |
| Parallax | rAF smoothed 3-layer parallax (text/frame/image) + `window.scroll` listener | **DROPPED for v1** — see Decision D-4 |
| Ambient theme swap | JS rewrites `document.body[data-theme]` as block enters viewport | **DROPPED for v1** — theme applied locally via `Section theme` prop. See Decision D-3 |
| CTA | Solid filled pill `<a>` | New filled-pill style local to the block (DS has no filled-link primitive). See Decision D-2 |

The block is **image-led, whitespace-heavy, low-chrome, single dominant CTA** — already aligned with the premium-editorial guardrails. Faithful adaptation requires no art-direction deviation.

## Component Anatomy (REQ-01, REQ-03)

New example block folder: `src/system/examples/FeatureSpotlight/`

> **Naming decision (D-1):** `Feature` alone is too generic and collides conceptually with framework "feature" terms. Existing MTG blocks use a descriptive PascalCase noun (`MTGHero`, `JourneyPanel`, `EditorialText`). **`FeatureSpotlight`** keeps the "feature" lineage of the source while reading as a concrete editorial block. (If the planner/user prefers, `LiveTheLifeFeature` is an acceptable alternative — flagged, not blocking.)

| File | Responsibility |
|------|----------------|
| `FeatureSpotlight.tsx` | Component. Top banner comment `// EXAMPLE — demonstrates foundations only.` per CONVENTIONS.md. Props: `{ content: FeatureSpotlightContent }`. Composes `Section` → `Container` → centered `Stack` (eyebrow, headline, lead, CTA) + media `figure`. Calls `useReveal()` once; applies a revealed class to the root. |
| `types.ts` | `export type FeatureSpotlightContent` (CMS-shaped). See shape below. |
| `FeatureSpotlight.module.css` | Block-local CSS: media frame clip/aspect/radius, rise-in entrance transitions + staggered delays, filled-pill CTA, `prefers-reduced-motion` guard. **No raw hex / no raw px** (ESLint/Stylelint enforced). |
| `FeatureSpotlight.stories.tsx` | Default story + a `pink-soft` themed story; reduced-motion handled by the global Storybook toolbar decorator. Uses fixtures from `src/stories/_fixtures/`. |
| `FeatureSpotlight.test.tsx` | Renders content; asserts eyebrow/headline/lead/CTA text + image `alt`; asserts CTA `href`; asserts content is visible without motion (reduced-motion / no-IO baseline). |
| `index.ts` | Barrel: `export { FeatureSpotlight, type FeatureSpotlightProps } from './FeatureSpotlight'` and `export type { FeatureSpotlightContent } from './types'`. |

**`FeatureSpotlightContent` shape (D-3 makes `theme` a prop, not ambient):**

```ts
export type FeatureSpotlightContent = {
  eyebrow: string          // "№ 01 — A life, not just a job"
  headline: string         // supports a line break; author with \n or a string[] of lines
  lead: string             // supporting paragraph, ≤ ~56ch target measure
  cta: { label: string; href: string }
  image: { src: string; alt: string }   // alt is required (Image primitive enforces)
  theme?: ThemeName        // default 'pink-soft' — local to the Section, not the page
}
```

**Composition (target idiom — follow `EditorialText` + `MTGHero` patterns):**

```
<Section theme={content.theme ?? 'pink-soft'} spacing="lg">     // theme local; no body mutation
  <Container size="default">                                    // editorial uses inner max-width 1200, centered
    <Stack gap="loose" align="center">  ← editorial column, text-align center, max-width ~1080
       Text role="tag"      → eyebrow
       Text role="display"  → headline   (source fs-5xl/lh-display maps to role="display")
       Text role="lead"     → lead        (source fs-lg/lh-lead maps to role="lead")
       CTA pill (block-local class, see Color/Copy)
    </Stack>
    <figure className={s.frame}>          ← media frame, full width, clipped, card radius
       <Image aspect="…" focalPoint="center" loading="lazy" />
    </figure>
  </Container>
</Section>
```

## Spacing Scale

The DS spacing scale is fixed by `src/tokens/semantic/space.ts` (8-point family). This block consumes existing **semantic** space roles only — never raw values, never `space[N]` directly.

| Token (CSS var) | Resolves to | Usage in this block |
|-------|-------|-------|
| `--space-section-y-lg` | 128px | Section top rhythm (source `.feature` `padding-top: section-y-lg`) |
| `--space-section-y-md` | 96px | Section vertical rhythm < 768px |
| `--space-content-gap` | 24px | Gap between editorial column and media frame (source `.feature__inner gap`) |
| `--space-stack-loose` | 32px (`space[5]`) | Vertical rhythm inside the editorial column (eyebrow→headline→lead→CTA). Mirrors source `gap: stack-loose`. |
| `--space-inline-default` | 8px | CTA label → arrow icon gap |
| `--space-3` / `--space-5` | 12px / 24px | CTA pill padding (`12px` block, `24px` inline) — mirrors source `.editorial__cta` padding |
| `--space-container-pad-{sm,md,lg}` | 16 / 24 / 32px | Responsive horizontal padding (via Container/Section) |

Exceptions: **none.** All spacing flows through existing semantic space tokens. No bespoke px gaps.

## Typography

Map source type onto existing `Text` roles (`src/tokens/semantic/type.ts`). Do **not** hand-style font sizes in the block CSS — use `Text role`.

| Source class | Source tokens | → DS role | Size token | Weight | Line height | Family |
|---|---|---|---|---|---|---|
| `.editorial__eyebrow` | `fs-2xs`, uppercase, tracking-tag | `Text role="tag"` | `--fs-2xs` | 400 | 1.2 | body (Object Sans) |
| `.editorial__headline` | `fs-5xl`, `fw-display-ultrabold`, `lh-display` | `Text role="display"` | `--fs-5xl` | 800 | 0.95 | display (Telegraf) |
| `.editorial__lead` | `fs-lg`, `lh-lead` | `Text role="lead"` | `--fs-lg` | 400 | 1.45 | body (Object Sans) |
| `.editorial__cta` | `fs-md`, `fw-display-ultrabold`, tracking-button | `Text role="button"` (inside the pill) | `--fs-md` | 800 | 1.0 | display (Telegraf) |

**Weights used: exactly 2** — 400 (body) + 800 (display ultrabold). This matches the DS (no 500/600 weight exists in the font set). The 8-point/3-4-size heuristic in generic UI specs is superseded here by the DS's role-based type scale, which is the project's type contract.

Measure constraints (from source, preserved): headline `text-wrap: balance`; lead `max-width: 56ch` + `text-wrap: pretty`.

## Color (no new palette — REQ-02)

The block carries its own theme via the `Section theme` prop. Default theme **`pink-soft`** (from source `data-theme="pink-soft"`). All colors resolve from theme semantic roles — **no raw hex anywhere** (Stylelint enforced).

Within the `pink-soft` theme the 60/30/10 reads as:

| Role | Semantic token | Resolves (pink-soft) | Usage in block |
|------|-------|-------|-------|
| Dominant (~60%) | `--color-surface-page` | `palette.pink[200]` | Section background — the warm field the block sits on |
| Secondary (~30%) | `--color-surface-raised` | `palette.pink[300]` | Media frame background (shows behind image while loading) |
| Text default | `--color-text-default` | `palette.neutral[800]` | Headline, eyebrow-on-surface |
| Text muted | `--color-text-muted` | `palette.neutral[700]` | Eyebrow, lead paragraph |
| Accent (~10%) | inverted text/surface on CTA | text-default bg + surface-page text | **The single CTA pill only** |
| Focus ring | `--color-focus-ring` | `palette.pink[700]` | Keyboard focus on CTA (global focus styles) |

**Accent reserved for:** the one filled CTA pill (`background: var(--color-text-default)`, `color: var(--color-surface-page)`) — exactly one dominant action per the editorial guardrails. Nothing else in the block is accented. No second/destructive color: this block has **no destructive actions**.

> The pill is "accent" by inversion (high-contrast dark-on-surface), faithfully reproducing the source `.editorial__cta`. This is intentional and AA-safe because `text-default` (neutral-800) on `surface-page` already passes the token contrast gate.

## Motion (REQ-04)

| Behavior | Source | This contract |
|---|---|---|
| Entrance reveal | `IntersectionObserver` adds `is-revealed`; `.rise` elements fade + translateY in, staggered by `--rise-d` (0/90/180/270/360ms) | Use **`useReveal()`** from `@system/hooks`. Apply a `revealed` class on the block root; children carry block-local `.rise` + per-child `--rise-d` stagger via inline `style`. Transition uses `--duration-slow` + standard easing (matches `motion.reveal` role). Visible end-state is the **base** style; the hidden pre-state only applies when JS has run AND motion is allowed. |
| Stagger order | eyebrow → headline → lead → CTA → media | same order; media travels slightly further (source `64px` vs `34px`) for a layered arrival |
| 3-layer parallax | rAF smoothed text/frame/image drift | **DROPPED (D-4).** Not reproduced in v1. No equivalent DS hook ships smoothed multi-layer parallax, and the brand guardrail is "restrained, purposeful motion." The image keeps a slight vertical bleed (`object-fit: cover`, frame `overflow: clip`) so the static crop still reads premium. Parallax may return as a later enhancement using a dedicated hook. |
| Reduced motion | `reduce` → instantly `is-revealed`, no rAF | `useReveal` already returns `revealed: true` at mount under `prefers-reduced-motion`; block CSS additionally guards `.rise` transitions inside `@media (prefers-reduced-motion: reduce)` so content is fully visible and static. **Required by REQ-04 + success criterion 2.** |

## Interaction Notes

- **CTA:** filled-pill anchor. Hover (only `@media (hover: hover)`): `opacity: 0.9` + `translateY(-1px)`, transition via `--motion-hover-duration`/`--motion-hover-easing`. Focus-visible uses the global token focus ring. Trailing `Icon name="arrow-right"` sized `--icon-md`.
- **Media frame:** `figure` with `border-radius: var(--card-radius)`, `overflow: clip`, aspect `1312/611` desktop → `4/5` under 768px (source). `Image` uses `loading="lazy"`, `object-fit: cover`, `focalPoint="center"`.
- **Accessibility:** Section labelled by the headline (`aria-labelledby` → headline id), matching source `aria-labelledby="feat-heading"`. Image `alt` is required by the `Image` primitive. Headline renders as `<h2>` (source uses `h2`; `Text role="display"` must render an `h2` tag here — pass the appropriate tag/role mapping).
