# Phase 2 — UI Design Contract

> Visual and interaction contract for the **Footer + CTA block** (`FooterCta`, variant **a** — "faithful outline"). Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **This is an ADAPTATION phase, not greenfield.** The visual direction is already decided by the source design exploration (`design-import/claude-design/MTG-blocks/footer-cta.{html,css,js}`, marked-final variant **a**). This contract specifies how that look maps onto the token-driven React design system — it does not re-invent the look. No new tokens, no new palette (hard constraint: PROJECT.md REQ-02 + brand guardrails). It follows the idiom established by the just-shipped Phase 1 block (`src/system/examples/FeatureSpotlight/`).

### Source Disambiguation (read before implementing)

The phase objective mentioned a "glow + watermark backdrop." **That backdrop is proposal C, not the marked-final variant a.** In `footer-cta.css`:

- `.footer-zone__bg { display: none; }` globally; only `[data-proposal="c"] .footer-zone__bg` sets `display: block`.
- `.glow` and `.watermark` are scoped exclusively under `[data-proposal="c"]`.
- Variant **a** (`[data-proposal="a"] .cta-pill--a`) is a **detached, no-fill outlined pill** (2px border, large radius) over the warmed body — **no glow, no watermark**.

Per PROJECT.md ("Use marked-final variants only … Footer+CTA = a") and "Out of Scope: Non-selected proposal variants (… CTA pills b/c)", **this contract implements variant a faithfully and does NOT port the C glow/watermark.** If the user later wants the glow/watermark, that is a separate, deferred enhancement.

**`FooterCtaContent` shape:**

```ts
import type { ThemeName } from '@tokens/themes'

export type FooterCtaContent = {
  runway: {
    eyebrow: string
    headline: string                 // supports a line break; author with \n or string[] of lines
    lead: string                     // ≤ ~54ch target measure (source max-width: 54ch)
    media?: { src: string; alt: string }   // OPTIONAL — see D-4. When omitted, runway is text-only.
  }
  cta: {
    eyebrow: string
    title: string                    // supports a line break; ≤ ~16ch measure (source max-width: 16ch)
    lead: string                     // ≤ ~46ch measure (source max-width: 46ch)
    action: { label: string; href: string }
  }
  footer: {
    columns: Array<{                 // source has 4 columns (first is "lead" / wider)
      tag: string                    // e.g. "An initiative of"
      items: Array<{ text: string; href?: string }>  // href optional → renders TextLink vs Text
    }>
    legal: string                    // "© Move to Gothenburg · 2026 · …"
    coords?: string                  // "57.7089°N · 11.9746°E" (tabular-nums)
  }
  runwayTheme?: ThemeName            // default 'neutral' (the cream runway)
  footerTheme?: ThemeName            // default 'amber' (the warmed footer end-state). 'amber-deep' for the deep story.
}
```

**Composition (target idiom — follows `FeatureSpotlight` + `EditorialText` + `MTGTopbar` footer patterns):**

```
<div className={s.root}>
  {/* ---- RUNWAY (neutral lead-in) ---- */}
  <Section theme={content.runwayTheme ?? 'neutral'} spacing="lg">
    <Container size="default">
      <Stack gap="loose">

      <div className={s.footCols}>
        {footer.columns.map(col => (

            <Text role="meta" as="p">{col.tag}</Text>

  </Section>
```

## Primitive Capability Notes (cross-checked against real primitive source — for planner/pattern-mapper)

Phase 1 found several spec↔primitive mismatches. Verified again for this block against `src/system/primitives/*`:

| Primitive | Capability | Implication for this block |
|---|---|---|
| `Text` | **No** `style`, **no** `id`, **no** `...rest` passthrough. Accepts `role`, `as`, `tone`, `className`, `children`. | The `--rise-d` stagger must ride a **plain wrapper `<div>`** (carrying `style` + `.rise`), NOT on `Text` (exactly the Phase 1 pattern). Cannot put `id` on `Text` for `aria-labelledby` — see a11y note below. |
| `Text` defaultTag | `display`→`h1`, `h2`→`h2`, `lead/body`→`p`, `tag/meta/button`→`span`. | CTA title needs `<h2>` → use `<Text role="display" as="h2">` (display gives the fs-5xl scale variant-a wants; `as="h2"` fixes the tag). Runway headline is the page `h1` → `<Text role="hero" as="h1">` (hero = fs-4xl, matching source `.runway__h` `--fs-4xl`). |
| `Section` | Spreads `...rest` (`HTMLAttributes`) onto `<section>`, so `id` / `aria-labelledby` / `aria-label` **do** forward. Has `theme`, `spacing` (`sm\|md\|lg\|xl`), `bleed`, `className`. **No ref forwarding.** | Theme + spacing handled by `Section`. `useReveal` ref must attach to an inner plain `<div>` (the CTA-pill wrapper), not `Section`. `aria-labelledby` can be set on the footer-zone `Section` if a heading id is available (but see a11y note — getting the id onto the heading is the constraint). |
| `Container` | Only `size` (`prose\|default\|wide\|bleed`), `as`, `className`, `children`. **No `...rest`, no ref.** | Source `.wrap` is `min(1440px)` centered with clamp padding; `Container size="default"` is the editorial centered container — use it. Do not expect to pass arbitrary props. |
| `Image` | `aspect` is a **named union** (`square\|portrait\|landscape\|wide\|cinematic`) — **no arbitrary ratios**. `radius` is `none\|sm\|md\|lg` — **no `pill`, no 32px**. Has `src`, `alt` (required), `focalPoint`, `loading`, `className`. | Source runway media is `aspect-ratio: 16/7` + `border-radius: 32px` — neither is an `Image` token. **Apply the 16/7 ratio + radius on the block-local `figure` wrapper** (`.runwayMedia`), let `Image` fill it `object-fit: cover` (Phase 1 did exactly this for the frame). |
| `Icon` | Glyphs limited to `arrow-right`, `check`, `map-pin`. Sizes `sm\|md\|lg`. | CTA arrow = `Icon name="arrow-right" size="md"`. No new glyph needed. |
| `TextLink` | Renders `<a>` with optional trailing `arrow`. Spreads anchor attrs. | Use for footer column links (`it.href` present). The big filled CTA button is **not** a `TextLink` (it needs the block-local filled-pill treatment) — author it as a block-local `<a>` (Phase 1 D-2 precedent). |
| `Surface` | `theme` + `className` + `children`, renders a `<div>`. No padding/border props. | Not required — the outlined pill is a styled `<div>` inside the amber `Section`; no extra Surface needed. |
| `Stack` | `gap` (`StackGap`), `align` (`StackAlign`), `className`. | Runway text column uses `Stack gap="loose"`. CTA pill internal rhythm is `gap: 24px` (= `stack-loose`) — achievable via the pill's own flex column in `.module.css` (the `.rise` wrappers need to be direct children for stagger, so author the pill as a styled container rather than `Stack` to keep full control of the wrapper structure). |
| `useReveal` | Returns `{ ref, revealed }`; `revealed: true` at mount under reduced-motion; constructs an `IntersectionObserver` in effect (mock in tests). | Attach `ref` to the CTA-pill wrapper `<div>`. Single hook instance. No parallax needed for this block (no parallax in source variant a). |

**Accessibility note on `aria-labelledby`:** because `Text` exposes no `id`, the Phase 1 block used `aria-label={headline}` on the root instead of `aria-labelledby`. For this block, set **`aria-label`** on the footer-zone region (e.g. `aria-label="Get started"` or the CTA title text) rather than wiring an id. If a true `aria-labelledby` is wanted later, the heading id would need a small `Text` enhancement (flag, non-blocking).

## Spacing Scale

The DS spacing scale is fixed by `src/tokens/primitives/space.ts` (base 4px, 8-point family) and consumed only through `src/tokens/semantic/space.ts` **semantic** roles — never raw values, never `space[N]` directly.

| Token (CSS var) | Resolves to | Usage in this block |
|-------|-------|-------|
| `--space-section-y-lg` | 128px | Runway `Section` vertical rhythm (source `.runway` `clamp(64,12vh,150px)` → nearest semantic large) |
| `--space-section-y-xl` | 192px | Footer-zone `Section` vertical rhythm (source footer `padding-top: clamp(72,11vh,150px)` + generous lead-in to the pill → `xl` spacing) |
| `--space-section-y-md` | 96px | Section vertical rhythm under 768px (responsive step-down) |
| `--space-stack-loose` | 24px (`space[5]`) | Runway text rhythm + **CTA-pill internal gap** (source variant-a `gap: 24px` → exact match) |
| `--space-stack-default` | 16px (`space[4]`) | Footer column item list `gap` (source `.footcol ul gap: 9px` → snap up to the nearest token, 16px reads premium) |
| `--space-stack-xl` | 48px (`space[7]`) | Gap between CTA pill and footer columns; gap between footer rows (source `.footcols gap: 40px 48px` → 48px column gap) |
| `--space-content-gap` | 32px (`space[6]`) | Runway text column → media figure gap; footer column row gap (source 40px → 32px token) |
| `--space-inline-default` | 8px | CTA button label → arrow icon gap (source `.btn gap: 10px` → 8px token); footer bar inline gap |
| `--space-3` / `--space-5` | 12px / 24px | CTA **button** padding (block `12px`, inline `24px`) — mirrors source `.btn padding: 15px 26px`, snapped to tokens |
| `--space-7` / `--space-9` | 48px / 96px | CTA **pill** padding: inline `~48px`, block `~96px` — mirrors source variant-a `padding: clamp(56–96px) clamp(28–72px)`, expressed with tokens (block 96 / inline 48) |
| `--space-container-pad-{sm,md,lg}` | 16 / 32 / 64px | Responsive horizontal padding (via Container) — source `.wrap padding-inline: clamp(20,5vw,112px)` approximated by the DS container scale |

Exceptions: **none.** All spacing flows through existing semantic space tokens. The source's `clamp()` fluid spacing collapses to discrete DS tokens with a sm/md/lg responsive step — this is the faithful DS-native expression, not a deviation.

## Color (no new palette — REQ-02)

The two regions carry their own themes via the `Section theme` prop. **No raw hex anywhere** (Stylelint enforced). The source's neutral→amber color-mix engine is replaced by two static themed sections that already exist in the DS.

**Runway region — `neutral` theme** (the cream lead-in):

| Role | Semantic token | Resolves (neutral) | Usage |
|------|-------|-------|-------|
| Dominant (~60%) | `--color-surface-page` | `neutral[50]` (cream) | Runway background |
| Secondary (~30%) | `--color-surface-raised` | `neutral[100]` | Runway media figure background (behind image while loading) |
| Text default | `--color-text-default` | `neutral[800]` | Runway headline |
| Text muted | `--color-text-muted` | `neutral[700]` | Runway eyebrow + lead |

**Footer-zone region — `amber` theme** (the warmed end-state; faithfully reproduces the source amber endpoints via the existing theme):

| Role | Semantic token | Resolves (amber) | Usage in block |
|------|-------|-------|-------|
| Dominant (~60%) | `--color-surface-page` | `amber[700]` (burnt orange) | Footer-zone background — the warm field the pill sits on (source `--amb-page #BB4B00` ≈ amber-700) |
| Secondary (~30%) | `--color-text-default` | `yellow[200]` (light yellow) | CTA title, footer wordmark (`currentColor`), footer legal-strong text (source `--amb-text #FFFD8C` ≈ yellow-200) |
| Text muted | `--color-text-muted` | `mutedOn(yellow[200])` | CTA/runway eyebrows, leads, footer list items, footer bar (source `--amb-muted`) |
| Pill outline | `--color-border-strong` | `color-mix(currentColor 28%)` | **CTA pill 2px outline** (source variant-a `border: 2px solid line` → `--border-strong` width + `--color-border-strong` color) |
| Footer dividers | `--color-border-subtle` / `--color-border-strong` | currentColor-mix | Footer bar top border (source `.footbar border-top: 1px solid line`) |
| Accent (~10%) | filled CTA button | button uses `--color-text-default` ground + `--color-surface-page` text | **The single CTA button only** |
| Focus ring | `--color-focus-ring` | `yellow[100]` | Keyboard focus on CTA + footer links (global focus styles) |

**Accent reserved for:** the **one filled CTA button** inside the outlined pill (`background: var(--color-text-default)`, `color: var(--color-surface-page)`) — exactly one dominant action per the editorial guardrails. Nothing else in the block is accented. No second/destructive color: this block has **no destructive actions**.

> The source variant-a button uses a distinct accent ground (`--c-accent`, blue→pale-yellow as it warms). The DS has no per-theme "accent surface" color role beyond `accent-line` (a line color, not a fill). To stay token-pure and high-contrast, the filled button uses **`text-default` on `surface-page`** (the same inversion Phase 1's CTA used) — AA-safe because the theme's text/surface pair already passes the contrast gate. This is a faithful, premium reading of the source's "one bright filled pill" intent without inventing a new accent-surface token. (Flagged as D-2; if the planner prefers, `accent-line` could tint the button, but inversion is the safer AA choice.)

`amber-deep` story: the source `[data-amber="deep"]` toggle (deeper `#5F1A00` page) maps to the existing **`amber-deep` theme** for `footerTheme` — no new tokens.

## Motion (REQ-04)

| Behavior | Source | This contract |
|---|---|---|
| Page-wide amber scroll engine | rAF/IntersectionObserver drives `--amber` 0→1; whole body color-mixes neutral→burnt-orange | **DROPPED for v1 (D-3).** Rendered as a static `amber` themed section. No scroll-color interpolation, no `document`/`html` mutation, no global side-effects. (Same call Phase 1 made for its ambient theme swap.) |
| Entrance reveal | None in source (source has no element entrance, only the color engine) | **Add** a restrained staggered rise on the CTA-pill contents via **`useReveal()`** (`@system/hooks`), consistent with `FeatureSpotlight`. Apply `revealed` class on the pill wrapper; children carry block-local `.rise` + per-child `--rise-d` stagger via inline `style`. Transition uses `--motion-reveal-duration` / `--motion-reveal-easing`. Visible end-state is the **base** style; the hidden pre-state only applies when JS has run AND motion is allowed. |
| Stagger order | n/a | eyebrow (0ms) → title (90ms) → lead (180ms) → button (270ms). Footer chrome is **not** reveal-animated (keep it calm; it is below the fold and utilitarian). |
| CTA button hover | `translateY(-2px)` + `gap` widens 10→16px, `transform 160ms` + `gap 220ms` easing-emphasis | Block-local: `@media (hover: hover)` → `transform: translateY(-2px)`, transition via `--motion-hover-duration` / `--motion-hover-easing`. (Drop the gap-widen micro-interaction — restrained; optional flourish, not required.) |
| Reduced motion | source `.btn { transition: none }`; amber engine reflects in-view state instantly | `useReveal` returns `revealed: true` at mount under `prefers-reduced-motion`; block CSS additionally guards `.rise` and `.ctaButton` transitions inside `@media (prefers-reduced-motion: reduce)` so content is fully visible and static. **Required by REQ-04 + success criterion (degrades gracefully).** |

No parallax in this block (variant a has none). No `useParallax` import needed.

## Interaction Notes

- **CTA button:** filled-pill anchor inside the outlined pill. Hover (only `@media (hover: hover)`): `translateY(-2px)`. Focus-visible uses the global token focus ring (`--color-focus-ring`, 2px offset, per `global.css`). Trailing `Icon name="arrow-right"` sized `--icon-md`. Label + icon are a single accessible link name.
- **CTA pill:** centered `<div>`, `border: var(--border-strong) solid var(--color-border-strong)`, `border-radius` large (source 64px → `calc(var(--radius-lg) * 4)` = 64px, the Phase 1 precedent for non-token large radii via `calc`; collapses to `calc(var(--radius-lg) * 2)` = 32px under 560px per source). Transparent background — the amber `Section` shows through. `padding: var(--space-9) var(--space-7)` (96/48) → step down under 768px.
- **Runway media (optional):** `figure` wrapper with `aspect-ratio: 16 / 7` (source), `border-radius: calc(var(--radius-lg) * 2)` (32px), `overflow: clip`, `background: var(--color-surface-raised)`. `Image` uses `loading="lazy"`, `object-fit: cover`, `focalPoint="center"`. Step to a taller ratio (e.g. `4/5`) under 768px for mobile legibility.
- **Footer columns:** CSS Grid `1.6fr 1fr 1fr 1fr` → `1fr 1fr` under 860px (first column spans full) → `1fr` under 560px (source breakpoints). Links via `TextLink`; non-link items via `Text`. The big wordmark SVG is decorative (`aria-hidden`, `role="img"` only if given a label — here it sits inside an `<a aria-label="Move to Gothenburg — home">`, so the SVG itself is `aria-hidden`).
- **Footer bar:** top border (`--color-border-strong`), flex row, wraps; coordinates use `font-variant-numeric: tabular-nums`.
- **Accessibility:** footer-zone region labelled via `aria-label` on the `Section` (set to the CTA title text — `Text` exposes no id so `aria-labelledby` is not wired; see Primitive Capability Notes). CTA title renders as `<h2>` (source `.cta__title` is an `h2`); runway headline as `<h1>` (source `.runway__h` is the page `h1`). Image `alt` required by the `Image` primitive. Footer wordmark link has an `aria-label`; the legal/coords text is plain readable text.
